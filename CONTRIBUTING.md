# Contribuir para o Quiz Bíblico

Obrigado pelo interesse em contribuir para o Quiz Bíblico.

O projecto foi originalmente criado por Eng. Dagmar Mpheio e é desenvolvido
com a colaboração da comunidade.

## Como contribuir

1. Faça fork do repositório.
2. Crie uma branch a partir da branch principal.
3. Implemente a alteração.
4. Execute os testes existentes.
5. Faça commits claros e descritivos.
6. Abra um Pull Request.

## Convenção de branches

Exemplos:

```text
feature/quiz-diario
feature/novas-perguntas
fix/resultado-quiz
refactor/question-repository
docs/readme
